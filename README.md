# Tiệm Nhà Thư - Handmade & DIY

Website bán hàng tĩnh, chạy miễn phí trên GitHub Pages.

## Cách dùng

1. Tạo repository GitHub tên `tiem-nha-thu.github.io`.
2. Upload `index.html`, `style.css`, `script.js` và thư mục `images`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch → main → / (root)**.
5. Mở `https://tiem-nha-thu.github.io/`.

## Thêm ảnh sản phẩm

Phiên bản mẫu đang dùng emoji để website chạy ngay. Bạn có thể thay phần `.product-image` bằng ảnh thật sau này. Nếu muốn quản lý sản phẩm dễ hơn, chỉ cần sửa mảng `products` trong `script.js`.

## Đặt hàng Zalo

Số Zalo hiện được cài là `0907808645`. Khi khách bấm đặt hàng, website tạo nội dung đơn hàng và mở trang Zalo của tiệm. Trình duyệt có thể yêu cầu quyền clipboard; khách có thể dán nội dung đã sao chép vào cuộc trò chuyện Zalo.
